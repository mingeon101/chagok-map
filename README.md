# 차곡지도 · 2026 미래교육 탐방 학부모회장 원정대

2026년 10월 27~28일 탐방 일정과 장소를 안내하는 읽기 전용 지도입니다.

- 제주공항 06:50 집결부터 시작하는 날짜별 일정
- 전체 일정표, 장소 설명, 주소, 방문 시간과 이동 안내
- 일반지도·위성지도와 카카오맵 장소 검색·길찾기 연결
- 일정 전체 보기에서는 순서 번호를 표시하고, 상세보기에서는 선택한 장소만 점으로 표시
- 편집·추가·삭제·순서 변경 기능 없음
- 날짜별 공유 링크와 기존 URL 파라미터 호환

빌드가 필요 없는 정적 HTML/CSS/JavaScript 사이트입니다. GitHub Pages의 `main` 브랜치 루트에서 배포합니다.

지도상의 연결선은 실제 도로 경로가 아닌 방문 순서입니다. 시간과 거리는 제공된 일정표 기준입니다.
